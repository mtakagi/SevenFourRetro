# テスト用の合成データ

`Tests/` の単体テストが使う合成データです。実在の掲示板・スレッド・利用者のデータは含みません。

- 読みやすさのため **UTF-8** で保存しています。テストでは `SFTestFixtureShiftJIS()` で Shift_JIS に変換し、サーバーの応答として使います（Shift_JIS で表せない文字は `&#N;` になります）。
- 移行検証用のデータ（#21）を作るときも、ここにあるデータを再利用できます。

| ファイル | 内容 |
| --- | --- |
| `bbsmenu.html` | 板一覧。カテゴリ 2 つ、板 3 つ。大文字・小文字の混在したタグを含みます。 |
| `subject.txt` | スレッド一覧。3 スレ。レス数が 1000 のスレを含みます。 |
| `thread.dat` | DAT。4 レス。ID・BE 付きのレス、`<br>` を含む本文、スレタイ付きの 1 行目を含みます。 |
| `thread-append.dat` | `thread.dat` の後に続く差分（2 レス）。差分取得（Range）のテストに使います。 |
