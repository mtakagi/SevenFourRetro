# Retro で複数スレを読み進める操作の記録（#22）

Swift 版（mtakagi/SevenFour#112）で同じ操作を比べるための、現行 Retro の挙動の記録です。Retro の UI はこの記録のために変えていません。気づいた問題は、最後の「Retro の既知の問題」にまとめました（修正は別の Issue で扱います）。

## 環境

| 項目 | 値 |
| --- | --- |
| Retro | `main` の 82d4474（#42 マージ後）。偽サーバーのデータはこの記録と同じブランチで追加 |
| macOS | 27.0.1（26A434）、Apple silicon |
| ビルド | Xcode 27.1、Release（Universal）を arm64 で実行 |
| 起動 | `Tools/run-app-with-test-home.sh`（一時的な HOME） |
| 板一覧 | `python3 Tools/fakebbs.py --port 8765` |
| 記録日 | 2026-11-08 |

### 設定

既定の設定のまま操作しました。読み進めに関わるものは次のとおりです（`SFAppController +setupUserDefaults`）。

| 設定 | 値 | 意味 |
| --- | --- | --- |
| `OpenThreadBySingleClick` | YES | スレッド一覧のクリック 1 回でスレを開く |
| `OpenThreadOnSubjectColumn` | YES | 開くのはタイトルの列をクリックしたときだけ |
| `ThreadShowAll` | NO | 本文はすべてではなく、新着と最後の数レスを表示 |
| `ThreadShowMin` | 10 | 新着が少なくても最後の 10 レスは表示 |
| `UseDrawer` | NO | 板一覧は左ペイン（3 ペイン） |
| `SplitVertical` | NO | スレッド一覧の下に本文 |

- メインウインドウは約 1100×650 ポイントで、スレッド一覧は 8 行ほど見えます。
- **注意**: 記録したときは、ウインドウの位置・大きさ・分割位置・一覧の列などのレイアウトに、以前の手動確認で保存された値が使われていました。起動スクリプトが設定（NSUserDefaults）を一時的な HOME に分けられていなかったためで、この記録と同じ PR で直しています（スクリプトは別のバンドル ID で起動し、終了時に設定を消すようになりました）。読み進めの挙動には影響しないはずですが、ウインドウの大きさは既定値と違う可能性があります。

### メニューのショートカット

| 操作 | キー |
| --- | --- |
| 新規タブ | ⌘T |
| タブを閉じる | ⌘W（タブが 1 つのときはウインドウを閉じる） |
| スレッドを更新 | ⌘R |
| 板を更新 | ⇧⌘R |
| 新規ウインドウ | ⌘N |
| 検索 | ⌘F |

## 合成データ（`Tools/fakebbs.py`）

実在の掲示板や利用者のデータは含みません。固定の規則で作るので、起動するたびに同じデータになり、Swift 版でも同じ板・スレで比べられます。書き込みはメモリ上だけに残り、サーバーを起動し直すと元に戻ります。

| 板 | URL | 内容 |
| --- | --- | --- |
| テスト板 | `/test/` | 2 スレ（スモークテスト用、従来どおり） |
| 読み進め板 | `/yomu/` | 40 スレ。1 番目は「長いスレ（300 レス）」、ほかは 3〜27 レス |
| 雑談板 | `/zatsu/` | 30 スレ（別の板へ移って戻る確認用） |

- 各レスの本文は「<スレタイ> の N つめ」で、10 レスごとに 1 つ前のレスへの安価（`>>N-1`）が付きます。
- 受け付けた書き込みは、そのスレの最後に追加されます。メール欄が sage でなければ、スレは一覧の先頭に移ります。
- スレのタイトルとレス数は次のとおりです。
  - 読み進め板: スレ 02 が 17、03 が 24、04 が 6、05 が 13、09 が 16、10 が 23、12 が 12
  - 雑談板: 読み進め板と同じ規則です

## 手順と結果

各段階で、板とスレッドの選択、スレッド一覧のスクロール位置、キーボードフォーカス、本文の表示を記録しました。Swift 版でも、この番号の順にたどってください。

### 1. 板を選ぶ

**操作**: 左ペインで「テスト」を開き、「読み進め板」をクリックする。

**結果**:
- スレッド一覧に 40 スレが出る。
- 一覧の先頭の行（長いスレ）が、選択色（グレー）で表示される。
- 左ペインの「読み進め板」は青い選択色で、キーボードフォーカスは左ペインにある。
- 本文タブは「Untitled」の空のまま。

### 2. 一覧をスクロールする

**操作**: スレッド一覧をスクロールして、7 番目を先頭にする。

**結果**: スクロールは一覧の中だけで、本文やほかのペインは動かない。

### 3. クリックでスレを開く

**操作**: スレのタイトルをクリックする（記録では 12 番目のスレ）。

**結果**:
- 今の本文タブに、そのスレが開く（タブは増えない）。タブの名前はスレタイになる。
- 一覧のスクロール位置はそのまま。開いたスレの行が選択され、既得と差分（12、0）が入る。
- 左ペインと一覧の選択色はどちらもグレーになる。
- ↓キーで一覧の選択も本文も動かず、キーボードフォーカスは見える場所にない。
- 本文は先頭（1 レス目）から表示される。

### 4. ⌘クリックで背面に開く

**操作**: 別のスレ（09、次に 10）のタイトルを ⌘クリックする。

**結果**:
- 新しいタブが右端に追加され、そのスレが読み込まれる。前面のタブは変わらない（背面に開く）。
- 一覧の選択は、⌘クリックしたスレの行に移る（選択は 1 行だけ）。
- タブの幅は 250 ポイントで、タブが増えると狭くなる（4 つで約 230）。

### 5. タブを切り替える

**操作**: タブをクリックして切り替える。

**結果**:
- 本文が切り替わる。
- 一覧の選択とスクロール位置は変わらない（選択はタブに合わせて動かない）。

### 6. 本文をスクロールする

**操作**: 本文をホイール・Page Down・End でスクロールする。

**結果**:
- 300 レスのスレは、ホイールと End でスクロールでき、End で 300 レス目が見える。
- 12〜23 レスのスレ（12、09、10）は、どの操作でもスクロールせず、5 レス目より後が見えない（「Retro の既知の問題」の 1）。
- 背面に開いたタブも、前面で開いたタブも同じ。

### 7. ⌘T・⌘W

**操作**: ⌘T を押し、次に ⌘W を押す。そのあと、真ん中のタブを選んで ⌘W を押す。

**結果**:
- ⌘T で、空の「Untitled」タブが右端に追加され、前面になる。スレ更新と書き込みのボタンは無効になる。
- ⌘W で、前面のタブが閉じる。
  - 右端のタブを閉じたときは、左隣のタブが前面になる。
  - 真ん中のタブを閉じたときは、右隣のタブ（その位置に詰めて入るタブ）が前面になる。
- 一覧には影響しない。

### 8. 別の板に移って戻る

**操作**: 読み進め板で一覧をスクロールし、スレ 09 を開く。「雑談板」に移り、一覧を一番下までスクロールしてから、「読み進め板」に戻る。

**結果**:
- 板を移ると、一覧の中身が入れ替わる。スクロール位置はそのまま引き継がれる（読み進め板で 7 番目が先頭なら、雑談板でも 7 番目が先頭）。
- 一覧の選択は消える。本文タブは前の板のスレ（09）を表示したまま。
- 読み進め板に戻ると、スクロール位置は雑談板で最後にいた位置のまま（23〜30 番目が見える）で、板ごとには覚えていない。
- スレ 09 の行は選択されていないが、既得（16）と差分（0）は表示される。

### 9. 新着を読む

**操作**: スレ 05（13 レス）を開き、「書き込む...」から書き込む（メール sage）。確認ダイアログで OK を押す。そのあと、本文右上の New をクリックし、⌘R を押す。

**結果**:
- 書き込みが完了すると、スレが自動で更新される（差分の 206 を取得）。
  - 一覧のレス数と既得は 14、差分は 0 になる。
- 本文は先頭のままで、追加された 14 レス目は、手順 6 と同じ問題で見えない。
- New をクリックすると少しだけスクロールするが、14 レス目までは届かない。
- ⌘R を押しても新着がないとき（サーバーは 416 を返す）は、表示は変わらない。
- このスレのタブの名前は「Untitled」のままだった（「Retro の既知の問題」の 2）。

## Retro の既知の問題

記録中に見つけた問題です。それぞれ Issue にしました。

1. **短いスレの本文がスクロールしない**（#44）。
   - 12〜23 レスのスレでは、ホイール・Page Down・End のどれでも本文が動かず、5 レス目より後と新着が見えません。300 レスのスレではスクロールできます。
   - #32 より前のビルド（1873496）でも同じだったので、最近の変更による退行ではありません。
   - 本文のビュー（旧 WebView）の大きさか、スキンの表示範囲に原因がありそうですが、まだ調べていません。
2. **タブの名前が「Untitled」のままになることがある**（#45）。
   - 次の場合に起きました: 長いスレをクリックで開いたとき（ほかのタブに切り替えると直る）、書き込んで自動更新されたとき。
3. **スレを開いたあと、キーボードフォーカスが見える場所にない**（#46）。 ↓キーで一覧も本文も動きません。

## Swift 版で比べるときの手順

1. Retro のリポジトリで `python3 Tools/fakebbs.py --port 8765` を起動する。
2. Swift 版の板一覧の URL を `http://127.0.0.1:8765/bbsmenu.html` にする（ATS がローカルの HTTP を許す設定が必要な場合があります）。
3. 上の 1〜9 を同じ板・同じスレでたどり、各段階の選択・スクロール位置・フォーカス・本文の表示を比べる。
4. 書き込みはサーバーを止めるまでメモリに残る。最初から比べ直すときは、サーバーを起動し直す。
